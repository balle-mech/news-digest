### [★★★★★] Microsoft 11月Patch Tuesday：Outlook CVE-2026-124194が野外悪用確認——1,094件を一括修正
**ソース:** [SecurityWeek](https://securityweek.com/exploited-outlook-zero-day-among-1094-flaws-patched-by-microsoft)

Microsoftが11月10日に公開した月例パッチ（脆弱性を修正するソフトウェアの更新プログラム）で、Microsoft OutlookのCVE（セキュリティ脆弱性に振られる管理番号）-2026-124194（CVSS（脆弱性の深刻度を0〜10で示すスコア）6.5）が野外悪用済みと確認された。特別に細工されたメッセージを開くと、ユーザーのNTLMv2認証情報（ハッシュ）が攻撃者に奪われるスプーフィング脆弱性で、CISAが同日KEV（CISAが管理する「実際に攻撃で使われた脆弱性」の一覧）に登録し、米連邦機関に11月24日を期限とした修正を義務付けた。今月の修正件数は1,094件に達し、Adobeも同日110件のパッチを公開している。Microsoft 365 Apps for EnterpriseおよびOffice LTSC 2021/2024ユーザーは速やかなアップデートが求められる。 ※スニペットのみ取得

### [★★★★☆] Windows SignDrop ゼロデイ（CLFS LPE）：PoC公開済み・パッチなし——全Windowsの8割が対象か
**ソース:** [BleepingComputer](https://bleepingcomputer.com/news/security/new-windows-signdrop-zero-day-gives-hackers-system-privileges)

研究者Abdelhamid Naceri（Nightmare Eclipse）が11月10日、WindowsのCLFS（Common Log File System、カーネルが使うログファイルシステム）の認証ロジック欠陥をつくPoC（概念実証コード）を公開した。ローカルユーザーがSYSTEM権限を取得できるLPE（ローカル権限昇格）脆弱性で、Windows 11 26H2とWindows Server 2025 Experimentalで動作が確認されている。同日公開の11月パッチには修正が含まれておらず、Microsoftは調査中としている。セキュリティ企業CyderesCorporationが独自にPoC動作を確認した一方、野外悪用の証拠はまだない。全Windowsインストールの約80%が影響を受ける可能性があり、企業のエンドポイント管理担当者は緩和策の適用と動向監視が急務だ。 ※スニペットのみ取得

### [★★★☆☆] KUSANAGI CVE-2026-117477：WordPress向けNginxのCRLFインジェクション——JVN公表
**ソース:** [ScanNetSecurity / JVN](https://scan.netsecurity.ne.jp/special/68/202611/Japan+Vulnerability+Notes%EF%BC%88JVN%EF%BC%89)

GMOプライムストラテジーが提供するWordPressサーバー高速化ミドルウェア「KUSANAGI」に脆弱性CVE-2026-117477が確認され、JVN（Japan Vulnerability Notes、国内の脆弱性情報データベース）に登録された。KUSANAGIのNginx設定ファイルに含まれるリダイレクトルールでCRLF文字（改行コードを使ってHTTPヘッダーに任意の行を挿入する）の無害化が不十分であり、HTTPヘッダーインジェクション（HTTPレスポンスに任意のヘッダーを注入する攻撃）が可能となる。セッションハイジャックやキャッシュポイズニングに悪用されるリスクがある。KUSANAGIは国内のWordPressホスティング環境に広く使われており、管理者は提供元のアドバイザリを確認の上、早急な対応が求められる。 ※スニペットのみ取得
